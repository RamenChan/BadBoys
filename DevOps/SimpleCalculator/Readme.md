## Basit Hesap Makinesi Projesi
Terminal üzerinden çalıştırılan,
Toplama, çıkarma, çarpma, bölme, mod alma işlemlerini gerçekleştirebilen,
Bu işlemleri terminal için hazırlanan hesap makinesi görünümde gösteren,
Temel bir proje geliştirildi.

Not;
Bu projeyi alıp, gelişmiş işlemleri yapabilecek konuda bir hesap makinesi tasarımına ilerlemeli miyim?
